CHITEC GameForge Creator — Updated Starter
===========================================
Created by CHITEC.

1. Extract this ZIP.
2. Open index.html in a browser to use the editor.
3. Add buildings, houses, trees, rocks, platforms, and coins.
4. Select Play Game and move with arrow keys or WASD.
5. Export Playable HTML downloads a standalone playable game.

For Netlify:
- Upload the extracted project files to your existing GitHub repository or deploy the folder to your existing Netlify site.
- Publish directory: . (the project root)
- Build command: leave blank.
